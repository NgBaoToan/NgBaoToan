# Engineering & Algorithms

A custom GitHub profile for Nguyen Bao Toan, software engineer, competitive programmer and third-year student at FPT University, Can Tho, Viet Nam.

## Profile structure

1. Animated banner and four contact links.
2. About me and two equal panels for software engineering and competitive programming.
3. Software engineering technologies and the developer toolbox.
4. Competitive programming introduction, practice platforms and the timestamped Codeforces snapshot.

The banner retains the requested C++17 code, bits/stdc++.h, using namespace std, four-space indentation, keyboard, mouse and steaming coffee.

## Editable assets

- README.md: profile content and links.
- assets/hero.gif: looping 1280 × 600 banner.
- assets/hero-static.svg: static and reduced-motion fallback.
- scripts/build_assets.py: vector asset source.
- scripts/build_hero_gif.py: GIF builder; requires Inkscape and Pillow.
- scripts/update_codeforces.py: Codeforces updater using Python's standard library.
